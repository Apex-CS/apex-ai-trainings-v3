# Blocked Topics

Requests matching any pattern in the section below are **hard-blocked** before the agent runs.
Edit the patterns list to tune what is rejected. Matching is case-insensitive substring search.

## Blocked categories (documentation)

- Malware, ransomware, or exploit development
- Credential theft, phishing kits, or social-engineering playbooks
- Instructions to attack a named company, person, or production system
- Unauthorized access to real customer, employee, or financial records
- Fabricating audit trails, financial statements, or regulatory filings
